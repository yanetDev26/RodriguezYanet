# Yanet Rodriguez — Portfolio

Next.js 15 (App Router, static export). Bilingual EN/ES.

## Run locally
```
npm install
npm run dev
```
Open http://localhost:3000

## Edit content
Everything (jobs, apps, stack, contact) lives in `lib/content.ts`.

## CV
Put your PDF at `public/cv/Yanet-Rodriguez-CV.pdf`.

## Deploy on Vercel (free)
1. Push this folder to a GitHub repo.
2. On vercel.com, sign in with GitHub → Add New → Project → import the repo.
3. Vercel detects Next.js; click Deploy. Every push to `main` redeploys.
